# 禁止操作

下列操作不得由 Agent 自行执行，应引导用户到浏览器：充值或支付、提现或结算、修改密码、配置支付/邮件/OAuth 凭据、签发兑换码、站长资金池操作。

删除 Key、批量改价、批量上下架必须先列出完整对象和变更清单，再取得逐次确认。

站长管理凭据只允许访问 `/api/v1/agent/station/*`。即使拿到写权限，也不得调用提现、资金池、客户余额调整、密码、佣金、支付/OAuth/邮件/银行凭据。模型与套餐写操作只能走 `changes/preview → changes/commit`，确认码一次有效且十分钟过期。

不得发送 `X-Aic-Studio`、`X-Aic-Tool-Site` 等内部请求头。只有用户明确要求固定商家且 Key 本身允许时，才可使用 `X-Aicoming-Provider`。

不得借用其他用户的 Key、伪装模型、绕过白名单、套餐或分站限制。
