# 凭据与网络安全

- Key 只发送给登录时绑定的主机；主机不一致立即拒绝。
- 所有携带 Key 的请求禁止跟随重定向。
- Key 不得进入聊天、命令行参数、stdout、stderr、debug 日志或错误文本。必要时最多显示 `sk-xxxx…` 前缀。
- 默认只保存到 `~/.aicoming/key`；目录权限 0700、文件权限 0600。Windows 使用 ACL 只保留当前用户。
- 除非用户点名要求并确认目标 `.env` 未被 Git 跟踪，不把 Key 写进项目。
- Agent 不接触账号密码，不通过用户名密码登录接口换 JWT。
- 支付、充值和订阅升级由用户在浏览器完成。
- 下载生成结果时不携带 Authorization。
